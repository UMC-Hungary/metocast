# WebSocket protocol

Generated by `cargo test -p metocast-server generated_docs` with `UPDATE_GOLDEN=1`; do not edit.

Connect to `ws://<host>/ws?token=<token>`. Send `{"type": "<command>", …fields}`. A command answers with `{"type":"ok"}`, `{"type":"error","message":…}` or a typed reply; replies carry no request id, so send one command at a time per socket.

## Messages the server sends

| Type | When | Fields |
|---|---|---|
| `automation.run` | An automation rule fired, with what it did | `run` object |
| `automations.changed` | The automation rules or the armed switch changed | `armed` boolean, `automations` array |
| `blackmagic-camera.discovered` | Reply to `blackmagic-camera.discover`: cameras found | `cameras` array |
| `broadlink.device.discovered` | A Broadlink device answered a discovery scan | `device` object |
| `broadlink.learn.result` | A learn session ended with a code, or timed out | `code` string?, `error` string? |
| `captions.job.state` | A caption job for a recording changed state | `jobId` uuid, `recordingId` uuid, `state` string, `progress` number, `error` string? |
| `clients.updated` | A client connected, disconnected or reported its label | `clients` array |
| `connected` | First message on every socket, with the server id | `serverId` string |
| `connector.state` | A connector's live state (OBS output, camera, ATEM, Middle Control) | `connector` string, `isStreaming` boolean?, `isRecording` boolean?, `streamStatus` string?, `hasMedia` boolean?, `state` object? |
| `connector.status` | A connector connected, disconnected or failed | `connector` string, `status` object |
| `cron.youtube_pull` | A scheduled YouTube pull ran | `hasLive` boolean |
| `event.changed` | A service event was inserted, updated or deleted, or a broadcast's `scheduleStatus` changed (`scheduled`, `starting`, `live`, `ended`) | `data` object |
| `event.order.changed` | An event's Order of Service was replaced; carries the new list | `eventId` uuid, `items` array |
| `keynote.status` | Keynote status, sent on connect and on change (macOS) | `status` object |
| `media.audio.progress` | Progress of an audio master render | `progress` object |
| `media.program.progress` | Progress of a program job: its render, a nudge, or transcripts added to it (step `captions`) | `progress` object |
| `media.render.progress` | Progress of a video render | `progress` object |
| `notification` | A message for the operator, with a level | `level` string, `message` string |
| `obs.state` | OBS streaming and recording state changed | `isStreaming` boolean, `isRecording` boolean |
| `order.state` | The Order of Service step on screen and its event's steps; sent on connect, on change and for `order.status` | `position` object?, `items` array |
| `ping` | Latency probe; answer with `pong` | `pingId` integer |
| `ppt.folders_changed` | The slide folders list changed | none |
| `ppt.index.state` | The slide library index started or finished parsing decks; also sent on connect | `indexing` boolean, `pending` integer |
| `ppt.search_results` | Reply to `ppt.search` | `files` array, `filter` string |
| `presentation.settings` | Reply to `presentation.get_settings`, and sent on change | `useWebPresenter` boolean, `presenterTheme` string |
| `presenter.slide_changed` | The presenter moved to another slide | `currentSlide` integer?, `totalSlides` integer? |
| `presenter.state` | The full web-presenter state | `state` object |
| `queue.stats` | Job queue counters; sent while any client is connected | `queues` array |
| `recorder.stopped` | A recording stopped: which recorder, why, and what it said | `target` object, `reason` string, `error` string? |
| `recorders.state` | The Record button's recorders: selected, connected, recording, last start | `recorders` array |
| `recording.changed` | A recording was inserted or updated | `data` object |
| `recording.detected` | A new recording file appeared on disk | `fileName` string, `eventTitle` string? |
| `recording.untracked.removed` | An untracked recording was assigned or deleted | `id` uuid |
| `rodecaster.audio.discovery` | Reply to `rodecaster.audio.discover` | `discovery` object |
| `rodecaster.mute` | A RØDECaster channel was muted or unmuted | `channel` integer, `label` string, `muted` boolean, `remote` boolean, `notify` boolean |
| `rodecaster.record.state` | The RØDECaster desk recorder state | `state` object? |
| `transcript.cleanup.state` | A stored transcript's AI clean-up ran a step, finished or failed | `sessionId` uuid, `state` string, `progress` number, `error` string? |
| `transcription.credit` | OpenAI credit balance for live transcription | `credit` object |
| `transcription.partial` | A live transcript line still being spoken | `text` string |
| `transcription.segment` | A finished live transcript line | `segment` object |
| `transcription.snapshot` | The transcript so far, sent on connect | `state` object, `segments` array, `partial` string?, `credit` object? |
| `transcription.state` | Live transcription started, stopped or failed | `state` object |
| `upload.completed` | An upload finished | `recordingId` uuid, `platform` string, `videoId` string, `videoUrl` string |
| `upload.failed` | An upload failed | `recordingId` uuid, `platform` string, `error` string |
| `upload.paused` | An upload paused | `recordingId` uuid, `reason` string |
| `upload.progress` | Bytes sent so far for an upload | `recordingId` uuid, `platform` string, `progressBytes` integer, `totalBytes` integer |

The same fields as JSON Schema: `docs/api/ws-events.schema.json`. A type ending in `?` may be null.

A command's reply reuses the command's own name as `type` (for example `events.list`).
